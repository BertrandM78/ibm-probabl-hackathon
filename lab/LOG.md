# Journal des expériences

Mémoire du lab : relu au début de chaque session. Une ligne par run complet de `lab/cv.py`
(ajoutée automatiquement), puis la colonne **Notes** est complétée à la main / par Bob.

- **CV RMSE** : RMSE OOF niveau visite, 5 folds GroupKFold par patient (`lab/folds.csv`).
- **Δ (apparié)** : moyenne ± écart-type des différences de RMSE fold par fold vs la référence
  (par défaut le meilleur run). Négatif = mieux.
- **Verdict** : `GAIN` si Δ < 0 et |Δ| > std(Δ) · `NOISE` sinon · `WORSE` si nettement pire.
  Un verdict auto se confirme dans les notes (ex. vérifier les sous-groupes dans `runs/<exp>/metrics.json`).
- Le détail chiffré complet est dans `lab/results.csv`.
